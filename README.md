# Sistema de Evaluación Psicométrica Adaptativa (CAT)

Plataforma de evaluación psicométrica adaptativa basada en Grafos Probabilísticos Ponderados y Procesamiento de Lenguaje Natural (NLP) determinista, desarrollada bajo una arquitectura Monolítica Modular desacoplada con interfaz REST (FastAPI + React).

---

## 📋 Requisitos Previos del Sistema

Antes de iniciar, verifica que tu equipo cuente con las siguientes herramientas instaladas:

* **Git**: [Descargar Git](https://git-scm.com/)
* **Python**: Versión 3.10 o superior ([Descargar Python](https://www.python.org/))
* **Node.js**: Versión 18.0 o superior (incluye `npm`) ([Descargar Node.js](https://nodejs.org/))

---
